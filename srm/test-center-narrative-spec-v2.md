# 테스트센터 내러티브 작성 기준 — v2

전체 정확도뿐 아니라 모듈 간 흐름(상승·유지·하락)을 읽어, 다음 수업에서 어떤 파트를 리뷰해야 하는지 방향을 제시하는 것이 목표.

---

## 입력 데이터

| 항목 | 설명 |
|------|------|
| `curriculumTitle` | 커리큘럼 제목 (예: "Digital SAT Full Test #3") — 없을 수 있음 |
| `curriculumDomain` | `"reading_and_writing"` \| `"math"` \| 기타 — 없을 수 있음 |
| `totalScore` | 전체 정답 수 |
| `totalProblems` | 전체 문항 수 |
| `lessons[]` | 모듈별 제목·정답·문항 수 배열 |

---

## 전처리 규칙

### 성취 분류 (`perfCtx`)

| 조건 | 값 |
|------|----|
| `accuracy ≥ 85` | 우수 |
| `accuracy ≥ 70` | 양호 |
| `accuracy < 70` | 보완 필요 |

### 도메인 표시 (`domainLabel`)

- `curriculumDomain`이 있으면 변환해서 사용
  - `reading_and_writing` → `RW`
  - `math` → `Math`
  - 기타 → 원문 그대로
- `curriculumDomain`이 없으면 lesson 제목에서 추론
  - 제목에 "math" 포함 → `Math`
  - 제목에 "reading" / "writing" / "rw" 포함 → `RW`
  - 해당 없으면 표시 생략

### 모듈 흐름 분류 (`trendNote`)

lessons가 2개 이상일 때만 계산. 첫 모듈과 마지막 모듈의 정답률 차이로 판정.

| 조건 | 값 |
|------|----|
| 마지막 - 첫 번째 > **+12%p** | 후반 모듈로 갈수록 성취가 올라가는 상승 흐름 |
| 첫 번째 - 마지막 > **+12%p** | 후반 모듈에서 정확도가 떨어지는 흐름 |
| 그 외 | 모듈 간 일관된 성취 |

### 약한 모듈 판정 기준

전체 평균 정답률보다 **10%p 이상 낮은 모듈**을 약한 모듈로 간주한다.

### 문장 수 결정

| 조건 | 문장 수 |
|------|---------|
| `curriculumTitle` 없음 **AND** `lessons ≤ 1개` | 2문장 |
| 그 외 | 3문장 |

---

## 내러티브 작성 원칙

1. 전체 정확도만 보지 않고 **모듈 간 흐름(상승·유지·하락)을 해석**한다
2. 전체 평균 정답률보다 10%p 이상 낮은 모듈이 있으면 **그 모듈을 구체적으로 지목**한다
3. `curriculumTitle`이 있으면 반드시 언급한다
4. 마지막 문장은 **다음 수업에서 어떤 파트를 리뷰할지**로 마무리한다

---

## User Content 예시

### 일반 세션 (3문장)

```
테스트: Digital SAT Full Test #3 (RW)
총점: 38/54 (70%) [양호]
모듈별: Module 1 - Easy: 22/27 (81%) | Module 2 - Hard: 16/27 (59%)
흐름: 후반 모듈에서 정확도가 떨어지는 흐름
전체 평균 정답률: 70% (이보다 10%p 이상 낮은 모듈을 약한 모듈로 간주)
```

### 정보 부족 세션 (2문장)

```
총점: 8/10 (80%) [양호]
모듈별: Module 1: 8/10 (80%)
전체 평균 정답률: 80% (이보다 10%p 이상 낮은 모듈을 약한 모듈로 간주)
```

## 엣지 케이스

| 케이스 | 처리 방법 |
|--------|-----------|
| `totalProblems === 0` | AI 호출 없이 내러티브 생략 |
| lessons 1개 | trendNote 생성 안 함 (흐름 언급 없이 생성) |
| `curriculumTitle` 없음 | 제목 언급 생략, lessons ≤ 1개면 2문장으로 단축 |
| 같은 날 세션 여러 개 | 세션별로 각각 내러티브 생성, 복수 노출 |
| `curriculumDomain` 없음 | lesson 제목에서 도메인 추론, 그래도 없으면 배지 생략 |
