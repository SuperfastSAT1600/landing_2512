# CRM 학생 카드 사이드패널 UX 개선 가이드

## 개요

세일즈 리드풀의 학생 카드를 클릭하면 오른쪽에 열리는 사이드패널(~440px)의 정보 입력/조회 화면을 개선한다. 핵심 목표는 **공간 효율성 향상**과 **정보 위계 명확화**이다.

---

## 현재 문제점

1. **공간 낭비**: "학부모 포털", "진단테스트 연결" 등이 각각 섹션 제목 + 버튼 + 설명 텍스트로 3줄씩 차지. 버튼 하나를 위해 섹션 하나가 존재.
2. **정보 위계 부재**: 인입 시 받은 정보(read-only)와 담당자가 입력하는 학생 정보가 같은 레벨로 나열.
3. **퍼널 단계 안내**: 현재 드롭다운 + 텍스트 안내 방식. 다음 행동이 시각적으로 약함.
4. **상담 메모**: 핵심 정보(ADHD, 해외 이주 예정, 소개 경로 등)가 자유 텍스트에 묻혀 있어 매번 전문을 읽어야 함.

---

## 개선 구조 (위에서 아래 순서)

### 1. 헤더

```
[학생 이름 (20px, bold)]                    [X 닫기]
[Y10 · 국제학교 · RW (13px, secondary)]
```

- 학생 이름은 크게, 바로 아래에 학년/학교/과목을 한 줄로.

### 2. 상태 뱃지 (이름 바로 아래)

```
[3b. 진단테스트 완료 (콜 전)]  [이탈 처리]
```

- 퍼널 단계와 학생 상태를 pill 뱃지로 표시.
- 퍼널 단계 뱃지는 **클릭 시 드롭다운**으로 단계 변경 가능 (비선형 이동 허용 — 담당자가 자유롭게 선택).
- 퍼널 = info 색상 계열, 학생 상태 = warning 색상 계열.
- 기존처럼 별도 드롭다운 섹션으로 빼지 않음.

### 3. 인입 정보 (read-only 영역)

```
섹션 레이블: "인입 정보"
```

- **배경색**: secondary 배경 (회색 계열), 테두리 없음.
- **편집 버튼 없음** — 받은 그대로의 데이터.
- key-value 테이블 형식:

| 키 (tertiary 색상, 30% 폭) | 값 |
|---|---|
| 문의일 | 2026-05-13 |
| 채널 | 구글 상담시트 |
| 소스 | (구)랜딩페이지 |
| 구분 | B2C |
| 핸드폰 | — |

- 폰트: 13px, padding 상하 4px로 촘촘하게.

### 4. 학생 정보 (편집 가능 영역)

```
섹션 레이블: "학생 정보"              [편집 버튼]
```

- **배경색**: primary 배경 (흰색) + 테두리 있음 — 인입 정보와 시각적 구분.
- **편집 버튼**: 섹션 레이블 오른쪽에 작은 "편집" 버튼. 이 카드 내부 정보만 수정 대상임을 명확히.
- 2열 그리드 레이아웃:

```
[학년]              [희망 과목]
Y10 · 국제학교       RW

[직전 점수]          [목표 점수]
미응시               미정

[목표 시험일]
미정
```

- 각 항목: 라벨 11px tertiary, 값 14px bold.
- 값이 미입력인 경우 tertiary 색상으로 "미정" / "미응시" 표시.

### 5. 빠른 액션

```
섹션 레이블: "빠른 액션"
```

- 한 줄에 버튼들을 나열 (flex, wrap 허용):
  - `[복사 아이콘] 학부모 포털 링크` — 클릭 시 링크 복사
  - `[링크 아이콘] 진단테스트 연결` — 클릭 시 진단테스트 결과 연결
- 기존에 각각 독립 섹션(제목 + 버튼 + 설명)이던 것을 버튼 한 줄로 압축.
- 버튼 스타일: outline, 13px, 아이콘 + 텍스트.

### 6. 다음 단계 배너

```
[→ 아이콘]  다음 단계: 세일즈 콜 진행
            진단테스트 제출이 완료되었습니다.
```

- info 배경색 배너.
- 현재 퍼널 단계에 따라 안내 메시지가 동적으로 변경.
- 배너 클릭 시 해당 액션으로 이동 (예: 세일즈 콜 완료로 퍼널 이동).

### 7. 상담 메모

```
섹션 레이블: "상담 메모"
```

#### 7-1. 기존 메모 카드

```
2026년 5월 23일 오후 9:15

[NLCS 제주] [ADHD] [정현성 컨설턴트 소개] [8월 싱가폴 이주 가능]

3월 SAT 1320점 (어머니 정확한 점수 모르심). 여름방학 사이언스 학원 특강 후
남는 시간에 SAT 집중 희망...
```

- 날짜: 12px tertiary.
- **태그**: 상담 메모에서 반복적으로 등장하는 핵심 정보를 pill 태그로 추출.
  - 태그 종류 예시: 학교명, 특이사항(ADHD 등), 소개 경로, 이주/일정 관련.
  - 각 태그는 카테고리별 색상 구분 (purple/amber/teal/coral 계열).
  - 태그는 본문 위에 위치하여 메모를 읽기 전에 핵심 파악 가능.
- 본문: 13px, line-height 1.6, secondary 색상.
- 메모가 여러 건이면 카드를 시간순으로 쌓음.

#### 7-2. 새 메모 입력

```
[textarea: "상담 내용을 입력하세요..."]
                                    [메모 저장]
```

- textarea: 최소 높이 60px, 리사이즈 가능.
- 저장 버튼: 우측 정렬, primary 색상 (어두운 배경 + 밝은 텍스트).

## 디자인 토큰 정리

| 요소 | 스타일 |
|---|---|
| 사이드패널 폭 | ~440px |
| 섹션 레이블 | 12px, font-weight 500, secondary 색상, letter-spacing 0.3px |
| 카드 (편집 가능) | 흰 배경, 0.5px 테두리, border-radius 12px, padding 12px 16px |
| 카드 (read-only) | secondary 배경, 테두리 없음, border-radius 12px, padding 10px 16px |
| 뱃지/pill | 12px, padding 3px 10px, border-radius 999px |
| 태그 (메모) | 11px, padding 2px 8px, border-radius 999px |
| 버튼 (outline) | 13px, padding 6px 14px, 아이콘 + 텍스트 |
| 버튼 (primary) | 13px, padding 6px 16px, 어두운 배경 + 밝은 텍스트 |
| 테이블 행 | 13px, padding 상하 4px |
| 그리드 (학생 정보) | 2열, gap 12px |

## 퍼널 단계 뱃지 동작 상세

- 뱃지 클릭 → 드롭다운 열림 (전체 퍼널 단계 목록 표시).
- **비선형 이동 허용**: 담당자가 어떤 단계로든 자유롭게 이동 가능.
- 단계 변경 시 "다음 단계 배너"의 안내 메시지도 연동 업데이트.
- 드롭다운 내 현재 단계는 체크 표시 또는 하이라이트.

## 참고: 기존 → 개선 매핑

| 기존 구조 | 개선 후 |
|---|---|
| 학생 정보 (편집 아이콘) — 문의일~핸드폰 + 학년~점수 혼재 | **인입 정보** (read-only) + **학생 정보** (편집 가능) 분리 |
| 퍼널 단계 드롭다운 (독립 섹션) | 헤더 아래 pill 뱃지 (클릭 시 드롭다운) |
| 학생 상태 (독립 섹션) | pill 뱃지로 퍼널 옆에 병합 |
| 학부모 포털 (독립 섹션: 제목 + 버튼 + 설명) | 빠른 액션 버튼 1개로 압축 |
| 진단테스트 연결 (독립 섹션: 제목 + 버튼 + 설명) | 빠른 액션 버튼 1개로 압축 |
| 상담 메모 추가 (독립 섹션) | 상담 메모 영역 하단에 통합 |
| 상담 타임라인 (자유 텍스트) | 태그 추출 + 본문 구조로 개선 |
