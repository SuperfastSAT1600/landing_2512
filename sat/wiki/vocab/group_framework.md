# SAT 단어장 그룹 분류 프레임워크

## 핵심 개념

세 그룹은 **언어학적 범주**가 아니라 **한국인 SAT 수험생의 인지 오류 유형**이다.
단어를 "모르는" 것이 아니라 "잘못 아는" 것이 SAT에서 더 위험하다.

---

## 그룹 정의

### Group A — 번역 터널 오류 (Translation Tunnel Error)
> **"한국어가 쪼개놓은 단어"**
> 영어는 하나인데, 한국어로는 문맥마다 다른 단어가 된다.

- **실패 메커니즘**: 학생이 가장 익숙한 한국어 번역 하나만 저장 → 다른 문맥에서 오답
- **처방**: 여러 번역을 하나로 묶는 **원형 이미지**로 복원
- **단어장 콘텐츠**: **뜻의 이미지** — 분기된 번역들을 아우르는 시각적 은유

**예시**

| 단어 | 한국어 번역들 | 공통 이미지 |
|------|-------------|-----------|
| `address` | 주소 / 연설하다 / 다루다 | "누군가/무언가를 향해 직접 가다" |
| `accommodate` | 수용하다 / 숙박시키다 / 적응시키다 | "상대에 맞게 공간/태도를 조정하다" |
| `critical` | 비판적인 / 결정적인 | "판단이 개입된 상태" |

---

### Group B — 의미 동결 오류 (Meaning Freeze Error)
> **"영어가 숨겨놓은 뜻"**
> 단어의 뜻이 하나라고 믿는다. SAT는 의도적으로 덜 알려진 뜻을 정답으로 쓴다.

- **실패 메커니즘**: 가장 흔한 뜻만 저장 → SAT가 노리는 두 번째/세 번째 뜻을 못 봄
- **처방**: 의미가 어떻게 분화했는지 어원으로 추적
- **단어장 콘텐츠**: **뜻의 뿌리** — 어원으로 분화 과정 설명

**예시**

| 단어 | 주요 뜻 | 숨겨진 뜻 | 뿌리 |
|------|---------|----------|------|
| `significant` | 중요한 | 의미심장한 (무언가를 암시하는) | 라틴어 *signum*(기호) — "기호를 만들다" |
| `distinct` | 다른 | 명확히 구분되는 | 라틴어 *distinguere* — "찌르다/구분하다" |
| `delicate` | 섬세한 | 까다로운 / 연약한 | 라틴어 *delicatus* — "유혹적으로 부드러운" |

---

### Group C — 형태 혼동 오류 (Form Conflation Error)
> **"우연히 같은 철자인 두 단어"**
> 철자가 같으니 같은 단어라고 믿는다. 실제로는 기원이 다른 별개의 단어다.

- **실패 메커니즘**: 다른 뜻을 같은 단어로 인식 → 문맥 신호를 무시하고 익숙한 뜻 선택
- **처방**: 연결하지 않는다. **분리해서 각각 처리**
- **단어장 콘텐츠**: **뜻의 분리** — `word¹` / `word²` 두 엔트리로 등록

> ⚠️ A/B와 반대 방향: A·B는 흩어진 뜻을 연결하는 작업이지만,
> C는 연결하려는 시도 자체가 학습을 방해한다. 억지 연결은 나중에 간섭을 일으킨다.

**예시**

| 단어 | 뜻¹ | 뜻² | 맥락 신호 |
|------|-----|-----|----------|
| `bank` | 강둑, 제방 | 은행, 저축 | 물/지형 vs 돈/금융 |
| `plant` | 식물 | 공장 | 생물/자연 vs 산업/설비 |
| `bark` | 나무껍질 | 짖다 | 나무/식물 vs 동물/소리 |
| `fair` | 공정한 | 박람회 | 판단/윤리 vs 행사/장소 |
| `light` | 빛 | 가벼운 | 시각/에너지 vs 무게/질량 |

## 세 그룹 비교 요약

| | Group A | Group B | Group C |
|--|---------|---------|---------|
| **오류 이름** | 번역 터널 오류 | 의미 동결 오류 | 형태 혼동 오류 |
| **핵심 문제** | 번역이 하나로 고정됨 | 뜻이 하나라고 믿음 | 다른 단어를 같다고 믿음 |
| **처방 방향** | 연결 (이미지로 통합) | 연결 (뿌리로 추적) | 분리 (별개 엔트리) |
| **단어장 콘텐츠** | 뜻의 이미지 | 뜻의 뿌리 | 뜻의 분리 |
| **판별 기준** | 한국어 번역이 2개 이상 | 영어 내 의미 분화 | 문맥 신호가 완전히 다름 |

## 공통 요소 — 문맥 신호 매핑

세 그룹 모두 최종적으로 필요한 것은 **"문맥 신호 → 뜻"** 매핑이다.
뜻의 이미지/뿌리/분리는 이해를 돕는 도구이고, SAT에서 실제로 문제를 푸는 행위는
passage의 신호를 감지해서 어떤 뜻인지 즉각 판단하는 것이다.

```
단어: address

뜻의 이미지: "누군가·무언가를 향해 직접 가다"
────────────────────────────────────────────────
문맥 신호 → 뜻:
  "an envelope / a letter / wrote the ___"     → 주소
  "addressed the crowd / the audience"         → 연설하다
  "we need to address this issue / problem"    → 다루다, 처리하다
```

## 판별 플로우차트

```
단어 입력
   │
   ▼
한국어 번역이 문맥에 따라 2개 이상인가?
   │
   ├─ YES → 뜻들 사이에 공통 이미지로 연결 가능한가?
   │           ├─ YES → Group A (뜻의 이미지)
   │           └─ NO  → Group C (뜻의 분리 — 별개 엔트리)
   │
   └─ NO  → 영어 내에서 뜻이 2개 이상인가?
               ├─ YES → Group B (뜻의 뿌리)
               └─ NO  → 일반 단어 (단순 암기)
```
