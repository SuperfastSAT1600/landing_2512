## 상위 15개 개념 태그 (빈도 기준)

### 1. Synthesis (227회)
**정의**: 여러 아이디어나 정보를 통합하여 새로운 의미 도출

**포함되는 스킬**:
- Rhetorical Synthesis (188개 중심)
- Command of Evidence
- Text Structure and Purpose
- Cross-Text Connections

**예시**:
- "저자의 주장 A와 B를 종합하면?"
- "두 텍스트의 공통점과 차이점은?"
- "여러 증거를 통합한 결론은?"

**학습 포인트**:
- 개별 정보만 아니라 전체 맥락 파악
- 서로 다른 증거들의 관계 이해
- 통합된 의미 도출

---

### 2-5. 어휘 관련 (226회씩)
#### 2. Vocabulary (226회)
- 단어의 정확한 의미
- 여러 뜻의 단어 구분
- 구체적 vs 추상적 어휘

#### 3. Context Clues (226회)
- 문맥에서 단어 의미 파악
- 전후 문장의 힌트
- 논리적 관계를 통한 추론

#### 4. Semantic Precision (226회)
- 정확한 의미의 단어 선택
- 비슷한 뜻 단어의 미묘한 차이
- 톤과 뉘앙스 구분

#### 5. Word Choice (226회)
- 문맥에 맞는 단어 선택
- 저자의 의도 반영
- 문체와 형식성 수준

**공통점**:
- 모두 "Words in Context" 스킬과 관련
- 정확한 어휘 이해 능력
- 총 904회 (RW의 52%)

#### 6. Textual Evidence (193회)

- 구체적 지지 제공

#### 7. Data Interpretation (193회)
- 수치/그래프 해석

#### 8. Charts (193회)

- 시각적 데이터 이해

#### 9. Quantitative Reasoning (193회)
- 수학적 논리
- 비율과 비교
- 데이터 기반 주장

### 11-15. 문법/구조 (180회씩)

#### 11. Verb Tense (180회)
- 시제 일관성

#### 12. Pronouns (180회)
- 대명사 참조 명확성

#### 14. Modifier Placement (180회)

#### 15. Evidence Integration (178회)
- 증거 통합 방식
- 인용문의 자연스러운 삽입

## 스킬별 개념 태그 분포

1. Textual Evidence (강함)
2. Synthesis
3. Evidence Integration
4. Inference/Implication

**특징**: 증거 기반의 텍스트 이해

### Craft and Structure (Words in Context)
**상위 태그**:
1. Vocabulary (강함)
2. Context Clues (강함)
3. Semantic Precision (강함)
4. Word Choice (강함)

**특징**: 단어와 문맥의 정확한 이해

**상위 태그**:
1. Subject-Verb Agreement (강함)
2. Verb Tense (강함)
3. Pronouns (강함)
4. Parallelism (강함)
5. Modifier Placement (강함)

**특징**: 문법 규칙의 정확한 적용

## 학습 경로 (개념 태그 기반)

### 기초 (1-2주)
1. **Basic Vocabulary** — 기본 단어 300개
2. **Subject-Verb Agreement** — 문법 기초
3. **Simple Context Clues** — 문맥 단서 인식

### 초급 (3-4주)
1. **Verb Tense** — 시제 일관성
2. **Semantic Precision** — 정확한 의미 구분
3. **Word Choice** — 문맥에 맞는 단어
4. **Pronouns** — 대명사 참조

### 중급 (5-8주)
1. **Parallelism** — 구조적 일관성
2. **Modifier Placement** — 수식어 정확성
3. **Textual Evidence** — 증거 찾기
4. **Evidence Integration** — 증거 통합
5. **Data Interpretation** — 통계 이해

### 고급 (9-12주)
1. **Synthesis** — 아이디어 통합
2. **Advanced Vocabulary** — 고급 어휘 (난이도 Hard)
3. **Rhetorical Strategy** — 표현 기법 분석
4. **Complex Reasoning** — 다층적 사고

## 주요 발견사항

### 1. 어휘 중심성 (52%)
- RW의 절반 이상이 어휘와 관련
- Words in Context 스킬 중요성 확대

### 2. 문법의 일관성 (23%)
- 5개 주요 문법 개념 (Agreement, Tense, Pronouns, Parallelism, Placement)
- Standard English Conventions 스킬의 핵심

### 3. 통합 사고 요구 (15%)
- Synthesis, Evidence Integration이 차이점
- 단순 암기가 아닌 이해 필요

### 4. 데이터 리터러시 (10%)
- Data Interpretation, Charts, Quantitative Reasoning
- 과학/사회과학 텍스트에서 필수
