# 이번 포스팅에서 배운 규칙

## 콘텐츠 측면

### 1. SAT 스킬명 번역 금지
- **규칙**: Inference, Words in Context 등 College Board 공식 스킬명은 영어 원문 고수
- **금지 예**: "추론 유형", "단어 선택"
- **허용 예**: "Inference 유형", "Inference 포인트"
- **Why**: College Board 공식 용어 준수로 신뢰성 유지. 독자 혼동 방지.

### 2. 시퀀스 = "구조"의 시각화
- **규칙**: 추상적 패턴(의도, 빈도)보다 **구체 시퀀스 예시** 3개 우선
- **근거 데이터**: 126개 Inference 문항 분석 → 상위 3시퀀스 각 2회 출현 → "패턴 없음"이 진짜 패턴
- **효과**: 독자가 "일관된 규칙은 없다"를 데이터로 납득 가능
- **다음 포스팅**: 다른 스킬도 시퀀스 3개 예시 기준으로 작성

### 3. 라벨 코드블록은 `sequence` 언어 힌트로
- **형식**: ` ```sequence ... ``` `
- **보존 요소**: [LABEL] 줄 + 한국어 본문 (일반 코드 아님)
- **이유**: 플랫폼별 변환 시 이 구조를 인식하기 위함

## 포스팅 구조 측면

### 4. "현상형" 유형 시그니처 재확인
- **C→R→E→I 구조**:
  - C (혼란 장면): 없음 (직접적) → 오프닝에서 "왜 어려운가?"로 암시
  - R (인식): 데이터 (126개 분석)
  - E (설명): 메커니즘 (College Board 출제 설계)
  - I (필연성): 구체 예시 (3시퀀스) + 결론 (패턴은 없다)

### 5. 클로징 강조 문장의 힘
- **규칙**: 결론부 강조 문장에 **역설적 반전** ("패턴을 찾으면 된다는 통념은 거짓")
- **효과**: 독자가 "그럼 뭘 해야 하나?"를 스스로 유도 → 행동 변화까지 이어짐
