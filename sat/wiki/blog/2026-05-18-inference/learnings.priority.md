# 우선순위별 배운 규칙

## [P1] SEMANTIC/Terminology — 스킬명 번역 금지
- **빈도**: 2회 (자주 발견)
- **규칙**: Inference, Words in Context 등 College Board 공식 스킬명은 영어 원문 고수
- **금지 예**: "추론 유형", "단어 선택"
- **허용 예**: "Inference 유형", "Inference 포인트"
- **근거**: College Board 공식 용어 준수로 신뢰성 유지. 독자 혼동 방지.
- **다음 포스팅 적용**: 초안 생성 후 정규표현식으로 자동 검사 (Inference, Words in Context, Command of Standard English, Expression of Ideas 등)

---

## [P2] STRUCTURAL/Section Order — C→R→E→I 구조 검증
- **빈도**: 1회 (중요도 높음)
- **규칙**: 현상형 포스팅의 필수 구조
  - C (혼란 장면): 구체적 시험 상황
  - R (인식): 데이터/패턴 제시
  - E (설명): 메커니즘 (왜 그런가)
  - I (필연성): 구체 예시 또는 행동 제시
- **금지**: 메커니즘 섹션이 데이터 제시 전에 오기 (논리 구조 붕괴)
- **다음 포스팅 적용**: FM-A Structural 검증 자동화

---

## [P3] META/Pacing — 시퀀스 예시 3개 vs 추상 패턴
- **빈도**: 1회
- **규칙**: 추상적 패턴("일반적으로", "대부분")보다 **구체 시퀀스 예시 3개** 우선
- **근거 데이터**: 126개 Inference 문항 분석 → 상위 3시퀀스 각 2회 출현 → "일관된 패턴 없음"이 진짜 발견
- **효과**: 독자가 "규칙은 없다"를 데이터 기반으로 납득 가능
- **다음 포스팅**: 다른 스킬도 "상위 3 패턴 + 빈도" 형식 고수

---

## [P4] STRUCTURAL/Platform Markers — :::마커::: 형식 표준화
- **빈도**: 1회 (플랫폼 확장에 필수)
- **형식**: 
  - `:::reader-profile ... :::` (독자 가정)
  - `:::quick-summary ... :::` (바쁘시면)
  - ` ```sequence ... ``` ` (라벨 코드블록)
- **목적**: blueprint.md에 표준화 → 플랫폼 어댑터가 자동 변환
- **다음 포스팅 적용**: 모든 new 포스팅이 이 3개 마커 필수 포함

---

## [P5] META/Closing Strategy — 역설적 반전
- **빈도**: 1회
- **규칙**: 결론부 강조 문장에 **역설적 반전** 포함
- **예시**: "패턴을 찾으면 된다는 통념은 거짓" (기존 믿음 + 반전)
- **효과**: 독자가 "그럼 뭘 해야 하나?"를 스스로 유도 → 행동 변화로 이어짐
- **다음 포스팅**: 반론 지도(Skeleton Gate)에서 오프닝 반전 최소 2개 확보

---

## [P6] SEMANTIC/Data Attribution — 출처 표기 규칙
- **빈도**: 0회 (이번 포스팅에서는 명확함, 하지만 반복 가능)
- **규칙**: "College Board Question Bank — [범위], SuperfastSAT 분석 (연도)"
- **금지**: "SuperfastSAT 문제 데이터베이스" (출처 오인 가능)
- **본문 서술**: "College Board Question Bank의 126개 문제를 SuperfastSAT이 전수 집계했습니다."
