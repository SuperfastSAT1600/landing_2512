# SAT RW 완전 분류 체계 (Complete Taxonomy)

**작성일**: 2026-05-11  
**데이터 기반**: College Board 1,527개 문제 분석 (`blog_database/sat_rw_reference.json`)  
**버전**: 1.0 (초기)

---

## 개요

SAT RW의 10개 스킬을 **문제의 객관적 특성 기준**으로 세분화하여, 각 스킬당 5-8개의 **세부 sub-skill**을 정의했다.

### 분류의 원칙

1. **문제 기준** — 학생의 오류가 아니라 문제의 구조적 특성으로 분류
2. **다차원성** — 각 스킬마다 2-3개 독립적 차원 제시
3. **명확한 경계** — 각 sub-skill 간 중복 최소화
4. **확장 가능성** — 새 문제/패턴 발견 시 추가 가능
5. **일관성** — 모든 10개 스킬이 동일한 원칙으로 분류

## 10개 스킬의 세부 분류 요약

### 1️⃣ Information and Ideas: Central Ideas and Details (CIA)

**특징**: "지문이 직접 말하는 것"을 정확히 파악
**주요 오답**: Out of Scope (57.5%) — 배경지식 간섭

| Sub-skill | 정의 | 난이도 |
|-----------|------|--------|
| CIA-1 | 지문 전체의 중심 주제 | Medium |
| CIA-2 | 저자의 주장/입장 | Medium |
| CIA-3 | 주제를 직접 지지하는 세부사항 | Easy-Medium |
| CIA-4 | 세부사항 간 숨은 연결고리 | Hard |
| CIA-5 | 주제의 범위 제한 | Hard |
| CIA-6 | 각 정보의 주제에 대한 역할 | Medium-Hard |
| CIA-7 | 사실과 의견의 구분 | Medium |

---

### 2️⃣ Information and Ideas: Command of Evidence (CoE)

**특징**: "주장을 가장 잘 뒷받침하는" 근거 찾기
**주요 오답**: Partial Match (35.4%) — 불충분한 근거 선택

| Sub-skill | 정의 | 난이도 |
|-----------|------|--------|
| CoE-1 | 주장과 근거가 직접 일치 | Easy |
| CoE-2 | 주장을 논리적으로 지지하는 근거 | Medium |
| CoE-3 | 여러 근거의 충분한 연결 | Medium-Hard |
| CoE-4 | 불충분한 근거 배제 | Hard |
| CoE-5 | 통계 범위와 주장 범위의 일치 | Medium-Hard |
| CoE-6 | 표/그래프 데이터 정확 해석 | Medium-Hard |
| CoE-7 | 반사실적 증거 (없음으로 증명) | Hard |

---

### 3️⃣ Information and Ideas: Inferences (INF)

**특징**: "지문에서 추론 가능한 것"과 "지문 초과"의 경계
**주요 오답**: Out of Scope (64.7%) — 지문 초과 추론

| Sub-skill | 정의 | 난이도 |
|-----------|------|--------|
| INF-1 | 한 문장에서 직접 읽을 수 있는 추론 | Easy-Medium |
| INF-2 | 여러 정보를 논리적 연결하여 추론 | Medium |
| INF-3 | 저자의 의도/태도/입장 추론 | Medium-Hard |
| INF-4 | 주장이 전제하는 암묵적 가정 찾기 | Hard |
| INF-5 | 추론의 범위 정확히 제한 | Hard |
| INF-6 | 문학적/상징적 표현 해석 | Hard |
| INF-7 | 주장에서 결론으로의 논리 체인 | Hard |

---

### 4️⃣ Craft and Structure: Words in Context (WIC)

**특징**: "사전적 정의" vs "문맥적 의미"의 구분
**주요 오답**: Distortion (43.6%) — 의미의 일부만 선택

| Sub-skill | 정의 | 난이도 |
|-----------|------|--------|
| WIC-1 | 문맥에서 단어의 정의 직접 제시 | Easy |
| WIC-2 | 여러 뜻 중 문맥에 맞는 하나 선택 | Medium |
| WIC-3 | 은유/비유의 실제 의미 파악 | Hard |
| WIC-4 | 단어의 감정/태도 뉘앙스 파악 | Medium-Hard |
| WIC-5 | 특정 분야에서만 쓰이는 의미 | Hard |
| WIC-6 | 문맥의 격식 수준에 맞는 선택 | Medium |
| WIC-7 | 문장 논리에서 유일하게 맞는 의미 | Hard |

---

### 5️⃣ Craft and Structure: Text Structure and Purpose (TSP)

**특징**: "저자가 왜 이 구조를 선택했는가"의 의도 파악
**주요 오답**: Out of Scope (55.2%) — 배경지식 기반 판단

| Sub-skill | 정의 | 난이도 |
|-----------|------|--------|
| TSP-1 | 단락이 전체 구조에서 하는 역할 | Medium |
| TSP-2 | 지문이 따르는 기본 구조 패턴 | Medium-Hard |
| TSP-3 | 정보가 제시되는 순서 파악 | Medium |
| TSP-4 | 저자의 설득 목적 | Hard |
| TSP-5 | 사용되는 설득 전략 | Hard |
| TSP-6 | 어느 정보를 강조하는가 | Medium-Hard |
| TSP-7 | 반론을 어떻게 처리하는가 | Hard |

---

### 6️⃣ Craft and Structure: Cross-Text Connections (CTC)

**특징**: Text1과 Text2의 관계 정확히 파악
**주요 오답**: Out of Scope (50.0%) — 두 텍스트 관계 오판

| Sub-skill | 정의 | 난이도 |
|-----------|------|--------|
| CTC-1 | Text1 저자의 입장 파악 | Medium |
| CTC-2 | Text2 저자의 입장 파악 | Medium |
| CTC-3 | 두 입장의 일치/동의 | Medium |
| CTC-4 | 두 입장의 대립/반박 | Medium-Hard |
| CTC-5 | 보완 관계 (한 텍스트가 다른 텍스트를 보충) | Medium-Hard |
| CTC-6 | 증거 관계 (Text2가 Text1의 근거 제시) | Medium-Hard |
| CTC-7 | 미묘한 관계 (부분 동의/부분 반박) | Hard |

---

### 7️⃣ Expression of Ideas: Rhetorical Synthesis (RS)

**특징**: Bullet-point 노트 → 완성된 문장
**특징**: CP 라벨링 분석에서 제외된 유일한 스킬

| Sub-skill | 정의 | 난이도 |
|-----------|------|--------|
| RS-1 | 목적에 관련 있는 정보 선택 | Easy-Medium |
| RS-2 | 무관한 정보 배제 | Medium |
| RS-3 | 정보들의 논리적 흐름 | Medium |
| RS-4 | 문법적 자연스러움/연결성 | Medium |
| RS-5 | 최종 문장이 주어진 목적과 일치 | Medium-Hard |
| RS-6 | 문맥의 톤/문체 맞추기 | Medium |
| RS-7 | 간결하게 표현 (불필요한 정보 제외) | Medium-Hard |

---

### 8️⃣ Expression of Ideas: Transitions (TRAN)

**특징**: "앞 문장과 뒤 문장의 논리적 관계"를 나타낼 정확한 전환어 선택
**주요 오답**: Pre-Pivot Reading (38.5%) — 전환점 이전만 읽음

| Sub-skill | 정의 | 난이도 |
|-----------|------|--------|
| TRAN-1 | 연속/추가 | Easy |
| TRAN-2 | 원인→결과 (인과) | Medium |
| TRAN-3 | 반대/대조 | Medium |
| TRAN-4 | 양보적 대조 (비록~이지만) | Hard |
| TRAN-5 | 구체적 예시 제시 | Easy-Medium |
| TRAN-6 | 상세 설명/재표현 | Medium |
| TRAN-7 | 시간 순서 | Easy-Medium |

---

### 9️⃣ Standard English Conventions: Boundaries (BOUND)

**특징**: 독립절과 종속절의 구분, 올바른 부호 사용
**주요 오답**: Partial Match (49.5%) — 부분적으로 맞는 부호

| Sub-skill | 정의 | 난이도 |
|-----------|------|--------|
| BOUND-1 | 독립절 (완전한 문장) 인식 | Easy-Medium |
| BOUND-2 | 종속절 (불완전한 문장) 인식 | Easy-Medium |
| BOUND-3 | 두 절의 연결 논리 판단 | Medium-Hard |
| BOUND-4 | 마침표(.) vs 반점(;) | Medium |
| BOUND-5 | 반점(;) vs 쉼표(,) | Medium-Hard |
| BOUND-6 | 쉼표(,)의 다양한 쓰임 | Medium |
| BOUND-7 | 콜론(:) & 대시(—) | Medium-Hard |

---

### 🔟 Standard English Conventions: Form, Structure, and Sense (FSS)

**특징**: "누가" 행동하는가, "무엇이" 주어인가를 정확히 파악
**주요 오답**: Misattribution (56.1%) — 주체/주인 오파악 (가장 높은 오답률)

| Sub-skill | 정의 | 난이도 |
|-----------|------|--------|
| FSS-1 | 주어-동사 수 일치 | Easy-Medium |
| FSS-2 | 주어-동사 의미 관계 | Medium |
| FSS-3 | 진짜 주인/주체 파악 | Hard |
| FSS-4 | 시제 일관성 | Medium |
| FSS-5 | 완료(have done) vs 진행(are doing) 구분 | Medium-Hard |
| FSS-6 | 수식어가 올바른 명사 수식 | Medium-Hard |
| FSS-7 | 대명사의 올바른 선행사 지시 | Medium |

## 적용 방법

### 학생 진단
각 스킬의 sub-skill별로 문제를 풀리고, 어느 sub-skill에서 약한지 파악

### 교육 설계
약한 sub-skill부터 집중적으로 가르침 (예: INF-5 범위 제한부터 시작)

### 문제 생성
각 스킬의 특정 sub-skill을 타겟한 문제 생성 가능

### 성과 측정
sub-skill별 정확도로 상세한 진행 추적
