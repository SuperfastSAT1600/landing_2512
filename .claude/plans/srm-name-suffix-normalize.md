# SRM 프로필 연결 — 이름 접미사 정규화

## 배경
CRM은 동명이인 방지를 위해 학생 이름에 숫자 접미사를 붙여 기록한다 (예: `박시연03`).
v2 학습 플랫폼 `profiles.full_name`은 순수 이름(`박시연`)이라, SrmDataCard의 v2 검색이
`ILIKE '%박시연03%'`로 돌아 항상 0건 → "일치하는 프로필이 없습니다".

## 목표
추가 데이터 입력 없이, v2 검색어에서만 끝자리 숫자를 자동 제거해 매칭되게 한다.
CRM 원본 이름은 변경하지 않는다.

## 요구사항

### REQ-001 (TEST) 이름 접미사 정규화 함수
`박시연03` → `박시연`, `박시연 03` → `박시연`, `박시연` → `박시연`(변화 없음),
`홍길동` → `홍길동`(숫자 없음 유지). 정규식 `/\s*\d+\s*$/` 로 끝의 공백+숫자 제거.

### REQ-002 (BROWSER) 프리필 검색어에 적용
SrmDataCard 미연결 상태의 검색 input 초기값을 정규화된 이름으로 채운다.
사용자가 이후 직접 수정하면 그 입력을 존중(정규화 재적용 안 함).

## 비범위
- v2-search 라우트의 phone/email 검색 확장(다음 개선)
- CRM 원본 이름 변경
