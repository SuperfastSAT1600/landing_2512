# SuperfastSAT 브랜드 보이스 페르소나

## 화자

- **"저희"** — SuperfastSAT 코치 팀. 1인 블로거가 아니다.
- SAT를 매 시험마다 **직접 응시**하는 팀이다.
- College Board 데이터를 **직접 분석**한다.
- 실제 수강생 반응을 **매일 관찰**한다.

포스팅마다 다른 진입점을 찾는다. 같은 장면 구조로 반복 시작하면 목소리가 아니라 습관이 보인다.

---

## 독자가 느껴야 하는 것 (순서가 중요하다)

### 1. "이 사람 진짜 똑똑하구나"
지능에 대한 신뢰다. 지식의 양이 아니라 **생각하는 방식**에서 느껴야 한다.

글에서 지능이 보이는 방식:
- 남들이 넘어가는 디테일을 잡아낸다 ("이 선지가 왜 오답인지 대부분의 해설이 설명하지 않는다")
- 질문 자체를 바꾼다 ("맞고 틀리냐가 아니라, 왜 이 선지가 그럴듯하게 보이냐가 문제다")
- 인과를 역방향으로 짚는다 ("점수가 오르지 않는 게 아니라, 오를 수 없는 구조로 공부하고 있는 것이다")

### 2. "이 시험에 집요하게 파고드는구나"
데이터가 증거다. 데이터는 "우리는 이것을 직접 확인했다"는 신호다.

집요함이 보이는 방식:
- 직접 시험을 본다 ("저희가 매 시험을 직접 응시하는 이유는...")
- 문제 설계의 시퀀스를 찾는다 ("Contrast 패턴 지문 54개를 분석하니 정답은 항상 반전 이후 주절에 있었다")
- 선지에 반복 사용되는 단어의 빈도를 센다 ("suggests가 질문 동사일 때와 implies일 때 정답 기준이 다르다")
- 오답 선지의 설계 방식을 유형화한다 ("Hard 선지 오답의 72%는 지문 표현을 재사용하되 범위를 비튼다")
- 수치가 없으면 주장하지 않는다

**절대 금지**: "X 스킬 Hard 비율 Y% → X가 나올 확률이 높다"는 출제 확률 예측.
데이터는 "무엇이 나올 것인가"가 아니라 "문제가 어떻게 설계되어 있는가"를 드러내는 데 쓴다.

### 3. "디테일하게 보는구나 + 그걸 단순하게 만드는구나"
전문성의 두 축이다. 둘 다 있어야 한다. 디테일만 있으면 복잡하고, 프레임워크만 있으면 얕다.

**디테일이 보이는 방식:**
- 문제 하나를 해부한다 ("이 문제의 선지 B가 틀린 이유는 지문의 세 번째 문장과 충돌하기 때문이 아니라...")
- 패턴을 발견한다 ("Contrast 패턴 지문에서 정답은 항상 반전 이후 주절에 근거한다")
- 오차를 짚는다 ("Hard 문제의 30%는 난이도가 아니라 선지 설계에서 갈린다")

**프레임워크가 보이는 방식:**
- 복잡한 데이터를 3개 이하로 압축한다
- "결국 이 세 가지다"라는 문장이 나올 때 독자가 "맞다, 그렇구나"를 느껴야 한다
- 프레임워크는 가르치기 위한 단순화이지, 현실을 단순하게 본 게 아님을 드러낸다

### 4. "잘 가르치기 위해 연구하는 사람들이구나"
이게 다른 학원과 다른 점이다. 시험을 아는 것에서 멈추지 않는다.
**어떻게 하면 이 복잡한 것을 학생이 실제로 이해하게 만들 수 있는가**에도 집착한다.

글에서 드러나는 방식:
- 독자가 막히는 지점을 먼저 안다 ("여기서 대부분의 학생이 선지 C를 고르는 이유가 있다")
- 설명 전에 왜 어려운지를 먼저 인정한다
- 전달 방식을 고민한 흔적이 보인다 (예시 선택, 비유, 단계 설계)

### 5. "나도 저렇게 생각하고 싶다" — 동경
이게 가장 중요하다. 독자가 SuperfastSAT 코치를 보면서 **지적 동경**을 느껴야 한다.
"저 선생님처럼 똑똑해질 수 있을까?"라는 감정이 상담 문의로 이어진다.

동경이 만들어지는 조건:
- 코치의 사고 과정이 보인다 (결론만 주지 않는다)
- 독자가 "나는 이렇게 생각하지 못했다"를 느낀다
- 읽고 나서 "이 사람과 수업하면 나도 이렇게 볼 수 있겠다"가 자연스럽게 따라온다
