# SuperfastSAT 문체 교정 사례집

글을 쓰기 전에 이 파일을 읽는다.
각 항목은 실제 교정 사례다. 같은 실수를 반복하지 않기 위해 존재한다.

---

## 교정 원칙

독자를 논리적으로 해부하지 않는다.
독자는 틀린 게 아니라 그렇게 알고 있었던 것이다.
그 사실을 인정한 뒤 자연스럽게 사실로 넘어간다.

---

## 교정 사례

### 01. "전제가 있습니다" — 독자를 논리 분해하는 표현

**금지**
```
"이 질문에는 전제가 하나 있습니다. 아이비리그 중 적어도 한 곳은 SAT 없이
지원 가능하다는 생각입니다."
```

**왜 금지인가**
독자가 질문을 던진 이유를 "전제"로 격상시키면, 글쓴이가 위에서 내려다보는
구조가 된다. 독자는 논리적 오류를 범한 게 아니라 그냥 그렇게 알고 있었던 것이다.
"전제", "가정", "함의" 같은 단어가 독자의 말을 분석 대상으로 만든다.

**대신**
독자가 그렇게 알고 있다는 것을 자연스럽게 인정하고, 바로 사실로 전환한다.

```
✓ "맞는 말이었습니다. 2026년 6월 12일 이전까지는."
✓ "그 말이 틀리지 않았습니다. 적어도 올해 초까지는."
✓ "그렇게 알고 계신 분들이 많습니다. 그런데 6월에 상황이 바뀌었습니다."
```

**적용 범위**
독자의 발화나 믿음을 받아서 전환할 때마다 적용한다.
"이 말에는 N가지 가정이 있습니다", "이 질문의 전제를 짚겠습니다" 모두 금지.

---

### 02. 독자의 감정을 추측해서 설명하는 표현

**금지**
```
"컬럼비아의 발표가 낯설게 느껴진다면, 컬럼비아가 이 흐름에서 마지막이었기
때문입니다."
```

**왜 금지인가**
독자가 실제로 그 감정을 느끼는지 알 수 없다. "낯설게 느껴진다면"은 독자에게
감정을 먼저 부여하고, 그것을 설명하는 구조다. 어색하고 불필요하다.
더 큰 문제는 독자가 실제로 궁금한 질문을 놓친다는 것이다.

**대신**
사실을 드라이하게 제시하고, 독자가 진짜 궁금해하는 "왜"를 바로 다룬다.

```
✓ "컬럼비아는 아이비리그 중 마지막으로 이 결정을 내렸습니다.
   그렇다면 왜 컬럼비아만 끝까지 버텼을까요?"
✓ [사실 제시] → [독자가 실제로 궁금한 질문] → [답]
```

**적용 범위**
"~게 느껴진다면", "~가 생소하게 느껴질 수 있습니다", "~가 놀라울 수 있습니다"
형태의 감정 추측 표현 전부.

---

### 03. 미국 대학 입시 포스팅에서 한국 학년제 사용

**금지**
```
"현재 고등학교 3학년이라면 / 고2라면"
```

**왜 금지인가**
미국 대학 입시를 다루는 포스팅에서 독자는 미국 학년제에 익숙하거나
그 기준으로 사고한다. 한국 학년제는 맥락에서 이탈한다.

**대신**
```
✓ Senior (12학년) — 현재 지원 사이클
✓ Junior (11학년) — 다음 사이클 준비
✓ Sophomore (10학년) — 장기 준비
```

**적용 범위**
미국 대학 입시, SAT 전략, 편입 관련 포스팅 전체.
한국 수능·내신·국내 대입을 다루는 포스팅은 예외.

---

### 04. 특정 집단 호명 — 그 집단에게만 해당하는 내용이 있어야 한다

**금지**
```
"한국 학생과 재미교포 수험생에게 이 변화가 의미하는 것"
→ (내용은 누구에게나 해당하는 일반론)
```

**왜 금지인가**
특정 집단을 호명하면 독자는 그 집단에게만 적용되는 정보를 기대한다.
내용이 일반론이면 호명 자체가 공허하고 신뢰를 깎는다.

**대신**
그 집단을 호명할 때는 반드시 그 집단에게만 해당하는 이유가 있어야 한다.

```
✓ 한국 유학생이 특별히 신경 써야 할 점이 실제로 있을 때만 언급
   예) F-1 비자 학생의 편입 경로 제약, AP 대체 불가 등
✗ 일반론을 그 집단에게 "해당된다"고 포장하는 것
```

**적용 범위**
"한국 학생", "재미교포", "국제학생" 등 특정 집단을 섹션 제목이나
본문에서 별도로 호명할 때마다 확인한다.

---

### 05. 확신의 강도 — 전문가는 두루뭉술하게 말하지 않는다

**금지**
```
"학생에 따라 다를 수 있습니다."
"이 방법도 고려해볼 수 있습니다."
"~하는 것이 중요합니다."
"~할 수 있습니다."
"알아보겠습니다."
```

**대신**
```
✓ "변명의 여지 없이 지금 공부에 문제가 있는 것입니다."
✓ "작년보다 어렵고, 6월보다 쉬웠습니다."
✓ "이 방법은 틀렸습니다."
```

**적용 범위**
주장이 데이터 또는 메커니즘으로 뒷받침될 때는 직선적으로 말한다.
근거 없이 확신 있게 말하는 것이 아니라, 근거가 있으면 완화 표현을 쓰지 않는다.

---

### 06. 억지 연결 — 사실의 가치만으로 충분한 경우가 있다

**금지**
```
출처에 없는 연결을 만들어내는 것.

예) 유펜이 수학 선수과목을 의무화했다 → (출처 없이) "따라서 SAT Math 점수가 더 중요해졌다"
```

**왜 금지인가**
독자가 모르는 사실을 알려주는 것 자체가 이미 충분한 포스팅이 된다.

거기에 연결을 덧붙이면 글이 더 깊어 보일 수 있지만, 그 연결이 출처에 없는 것이라면 오히려 신뢰를 깎는다. 전문가답다는 것은 모든 것을 연결하는 것이 아니라, 연결할 수 있는 것과 없는 것을 구분하는 것이다.

**대신**
사실을 사실로 전한다. 연결은 출처가 있을 때만 한다.

```
✓ "유펜이 수학 선수과목 이수를 의무화했습니다. 학년별로 무엇을 해야 하는지 정리했습니다."
✗ "유펜이 이 결정을 내린 것은 SAT Math 점수를 수학 준비도 신호로 보기 시작했기 때문입니다."
   (유펜이 이렇게 말한 적 없음)
```

**적용 범위**
입시 뉴스, 대학 정책 변화 포스팅 전체.
Skeleton Gate 주장 추적표에서 출처가 없는 연결 주장은 등록 불가.

---

### 07. 막연한 표현 — 수치로 대체한다

**금지**
```
"많은 학생이", "대부분", "높은 비율로"
"~일 것입니다", "~라고 생각됩니다" (데이터 없이)
"~하는 것이 좋습니다", "~를 추천드립니다"
"저희도 완벽하지 않지만" (면피성 문장)
```

**대신**
실제 수치로 대체한다. 수치가 없으면 주장하지 않는다.
데이터 없이 추측할 때는 "이런 경우가 있습니다" / "많은 경우" 등 완화 표현을 의무로 쓴다.

**적용 범위**
본문 전체. 수치 없는 주장이 나올 때마다 확인한다.

---

### 08. 오프닝 패턴 반복 — 연속 포스팅에서 같은 장면으로 시작하지 않는다

**금지**
```
나란히 발행되는 포스팅이 같은 구조로 시작되는 것.

예) 두 포스팅이 모두 "저희가 상담을 하다 보면~" 또는
    "상담 중에 이 질문을~"으로 시작.
```

**왜 금지인가**
같은 블로그에서 나란히 읽히는 포스팅이 동일한 오프닝 패턴을 쓰면,
글쓴이의 시각이 아니라 글쓴이의 습관이 먼저 보인다.

**대신**
상담 장면 없이 독자의 상황을 직접 서술한다.

```
✓ "조지타운을 목표로 하는 학생 중 SAT를 한 번만 보겠다는 계획을 세운 경우가 있습니다.
   모든 회차 점수를 제출해야 했기 때문입니다."
✗ "저희가 상담을 하다 보면 이런 말을 자주 듣습니다."
   (같은 패턴이 직전 포스팅에 이미 쓰였을 때)
```

**적용 범위**
포스팅 작성 전 최근 발행된 포스팅의 오프닝을 확인한다.
같은 장면 구조가 이미 쓰였다면 다른 각도로 시작한다.

### 09. 전문가의 확신 조율 — 처방과 선호를 구분한다

**원칙**
진짜 전문가는 단정해야 할 것과 여지를 둬야 할 것을 구분한다.
이 구분 자체가 전문성을 보여준다.

**처방형 (Prescriptive)**: 단 하나의 올바른 방법이 있는 것
```
✓ "M1은 전체를 한 번 검토한 상태로 제출해야 합니다."
✓ "이 방법은 틀렸습니다."
```
→ 단정적으로 쓴다. 완화 표현 없음.

**선호형 (Preference)**: 유효한 방법이 복수 존재하는 것
```
✓ "저희는 Desmos와 손풀이를 교차 검증하는 방식을 추천합니다."
✓ "아래 소개하는 방법이 유일한 방법은 아닙니다. 코치마다 디테일은 다를 수 있습니다. 다만 ___만큼은 모두 동의합니다."
```
→ "저희는 이것을 추천합니다" 형태로 쓴다. 다른 접근이 존재함을 인정하는 것이 신뢰를 높인다.

**금지**
```
✗ 처방형인데 완화 표현을 쓰는 것: "이 방법도 고려해볼 수 있습니다" (데이터가 단정을 지지할 때)
✗ 선호형인데 유일한 방법인 것처럼 쓰는 것: 복수의 유효한 방법이 있음을 숨기는 것
```

**실전 판별 기준**
포스팅 내용이 `teaching-content.md`의 [처방형]에 있으면 단정.
[선호형]에 있으면 "저희는 ~을 추천합니다"로 프레이밍.
분류가 불분명하면 선호형으로 처리한다.

### 07. 중간 제목 (H2/H3) — 금지가 아니라 권장

**원칙**
중간 제목은 독자의 가독성을 돕는다. 사용한다.

**금지와 구분**
이전에 금지한 것은 중간 제목 자체가 아니라 아래 형식이다.
- TL;DR 박스 / 요약 박스
- ## FAQ / ## 자주 묻는 질문 섹션
- 글 상단의 번호 목차 리스트
- "여기서 반전", "핵심은 이것" 구조 신호 레이블

**올바른 중간 제목**
글의 인식 흐름에서 자연스럽게 나오는 제목이어야 한다.

```
✓ "컬럼비아가 마지막이었던 이유"
✓ "이 결정이 수험생에게 의미하는 것"
✗ "## FAQ"
✗ "## 핵심 요약"
✗ "## 목차"
```
