# Brainstorming Command

Activate advanced N-dimensional brainstorming mode to deconstruct problems, challenge premises, and generate paradigm-shifting solutions.

---

## Purpose

Go far beyond surface-level idea generation. Dismantle assumptions, brainstorm across meta-categories, and produce solutions that render the original question obsolete.

---

## When to Use

- Exploring a problem space before committing to any approach
- Challenging entrenched assumptions about a system or feature
- Generating non-obvious solutions to hard problems
- Strategic planning where conventional thinking is insufficient
- Any time you need ideas that go beyond "list 10 options"

---

## Workflow

```
User: "/brainstorming <topic or question>"

Agent:
1. Load brainstorming skill
2. Deconstruct the user's premise
3. Identify hidden assumptions and invisible scaffolding
4. Generate meta-categories of solutions
5. Evaluate frameworks used to judge those categories
6. Ascend recursively to highest vantage point
7. Output paradigm-shifting solutions
```

---

## Example Usage

```bash
# Product strategy
/brainstorming "how should we monetize our developer tool?"

# Architecture
/brainstorming "what's the right database for our real-time app?"

# Feature design
/brainstorming "how to make onboarding frictionless"

# Business
/brainstorming "how to differentiate in a crowded market"
```
