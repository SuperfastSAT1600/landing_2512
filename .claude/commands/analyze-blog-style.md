# /analyze-blog-style

`blog_database/style_samples.jsonl`의 원본↔수정 쌍을 분석해,
반복 수정 패턴을 추출하고 `.claude/skills/superfastsat-blog/SKILL.md`의
**배코치 문체 DNA** 섹션을 직접 업데이트합니다.

---

## 실행 단계

### STEP 1: 데이터 수집

```bash
python .claude/scripts/analyze_style_patterns.py
```

JSON 리포트를 읽고 다음을 파악합니다.
- `total_samples`: 샘플 총 개수
- `dominant_change_types`: 가장 자주 발생한 변화 유형 (줄바꿈_증가, 문장_단축 등)
- `avg_structural_changes`: 평균 구조 변화 (단락 수, 문장 길이 등)
- `samples[].diff_preview`: 실제 편집 내용

### STEP 2: 패턴 해석 (LLM 분석)

Python 리포트를 읽은 뒤, **모든 샘플의 `diff_preview`** 를 직접 읽고
아래 5가지 차원으로 패턴을 해석합니다.

#### 분석 차원

1. **문장 리듬** — AI 초안과 비교해 문장을 더 짧게 자르는가, 길게 연결하는가?
   - 예: 긴 문장을 2개로 나누는 패턴 → "한 문장 = 한 개념" 규칙 도출

2. **줄바꿈·단락 구조** — 줄바꿈을 추가하는 경향인가, 제거하는 경향인가?
   - 예: 강조 부분에 단독 줄 추가 → "강조 문장은 단독 줄로" 규칙 도출

3. **어휘·표현 치환** — 특정 단어/표현을 반복적으로 다른 표현으로 바꾸는가?
   - 예: "확인하시면" → "보시면" 반복 치환 → 특정 표현 금지 규칙 도출

4. **내용 추가/삭제** — 어떤 유형의 내용을 추가하고, 어떤 내용을 삭제하는가?
   - 예: AI 설명 문단을 삭제하고 질문형 문장으로 대체 → 구조 선호 규칙

5. **톤·감성** — 더 직접적으로 만드는가, 더 부드럽게 만드는가?
   - 예: "~하셔야 합니다" → "~하시면 됩니다" 치환 패턴

### STEP 3: 규칙 도출

각 차원에서 **2개 이상의 샘플에서 반복된 패턴**만 규칙으로 채택합니다.
단 1회 수정은 일회성으로 간주하고 제외합니다.

규칙 형식:
```
**[규칙 이름]** (N회 관찰)
- 패턴: AI가 X를 쓰면 → 사용자가 Y로 수정
- 규칙: [SKILL.md에 추가할 구체적 문장]
- 예시: before: "..." / after: "..."
```

### STEP 4: SKILL.md 업데이트 제안

도출된 규칙을 `.claude/skills/superfastsat-blog/SKILL.md`의
**배코치 문체 DNA** 섹션에 추가하는 diff를 제시합니다.

형식:
```
## 제안하는 SKILL.md 변경사항

### 추가할 규칙 (배코치 문체 DNA 섹션)

**⑨ [규칙 이름]** (style_samples 분석 기반)
- [구체적 규칙 내용]
- 예시: ...

**⑩ [규칙 이름]** (style_samples 분석 기반)
- [구체적 규칙 내용]
```

### STEP 5: 사용자 승인 후 반영

제안 후 **반드시 사용자 확인을 기다립니다.**

사용자가 "적용해줘" 또는 "OK" → SKILL.md를 직접 편집합니다.
사용자가 수정을 요청 → 규칙을 조정한 뒤 재제안합니다.
사용자가 거절 → 해당 규칙은 건너뜁니다.

## 실행 조건

- 샘플 3개 미만: "샘플이 부족합니다. 미리보기 서버(http://localhost:3333)에서 포스팅을 편집 후 저장하면 자동으로 쌓입니다." 라고 안내하고 종료합니다.
- 샘플 3~9개: 패턴 신뢰도 낮음을 명시하고 진행합니다.
- 샘플 10개 이상: 신뢰도 높음, 구체적 규칙을 더 확신 있게 제안합니다.

---

## 샘플이 쌓이는 방법

1. `node preview-blog.js` 실행 → http://localhost:3333
2. AI가 생성한 블로그 초안을 `content/posts/` 에 저장
3. 미리보기에서 직접 편집
4. **[💾 저장 & 학습]** 클릭 → `blog_database/style_samples.jsonl`에 자동 기록
5. N개 쌓이면 `/analyze-blog-style` 실행

---

## 업데이트 이력

SKILL.md가 업데이트될 때마다 해당 규칙에 `(style_samples 분석 기반, YYYY-MM-DD)` 태그를 붙입니다.
이를 통해 어떤 규칙이 실제 편집 데이터로부터 도출되었는지 추적합니다.
