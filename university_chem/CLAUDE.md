# University Destiny Match (대학 궁합)

## 한 줄 요약
생년월일을 입력하면 QS 세계 대학 랭킹 1-100위 중 하나와 사주 오행 기반 "케미"를 매칭하고, 친구들과 결과를 그룹 지도로 공유할 수 있는 바이럴 콘텐츠 웹앱.

## 배경 & 목적
- 운영 주체: Argonaut AI (아르고노트에이아이) — SuperfastSAT(SAT/AP 준비 서비스) 운영사
- 목적: SAT/대학입시에 관심 있는 학생들이 재미 삼아 결과를 인스타그램 등에 공유하도록 유도하는 바이럴 훅
- 톤: 운세/사주 감성의 가벼운 엔터테인먼트. 실제 입시 결과와 무관함을 명시 (면책 문구 유지)

## 현재 상태 (2026-08-15 기준)

### 완료된 기능
- **오행 매칭**: 사주 오행(년주·계절·일진) 프로필 계산 → QS 1-100위 103개교에 대해 코사인 유사도 매칭
- **SAT 필터링**: 미국 대학 10곳 SAT 중간 50% 범위 반영, 점수 기반 후보 풀 필터링
- **픽셀 아트 배지**: 학교명 해시 기반 알고리즘 생성 (103개교 모두 자동 적용)
- **그룹 보드**: URL 해시(`#g=`) 인코딩으로 백엔드 없이 최대 10명 그룹 공유
- **닉네임 초대 흐름**: 결과 카드 하단 닉네임 입력 → 그룹 URL 복사 → 친구 초대
- **해시 라우팅**: `#g=` URL 진입 시 그룹 보드 즉시 표시, hashchange 이벤트로 양방향 전환

### 3개 화면 구성
1. **퀴즈 폼**: 생년월일 + SAT 점수(선택) 입력
2. **결과 카드**: 대학 배지 + 궁합% + 오행 칩 + 플레이버 문장 + 모토 + 닉네임 초대 섹션
3. **그룹 보드**: 103개교 카드 그리드, 배정된 친구 이름 칩 표시, "나도 참여하기" 고정 하단바

### 공유 플로우
```
나: 퀴즈 → 결과 → 닉네임 "지수" → "친구 초대하기" → URL 복사
                                        ↓
친구A: 링크 열면 → 그룹 보드 (지수 위치 확인) → "나도 참여하기" → 퀴즈 → 닉네임 → 새 URL 복사
                                        ↓
친구B, C, D... (최대 10명까지 반복)
```

### URL 인코딩 형식
```
#g=닉네임1:대학인덱스:궁합%,닉네임2:대학인덱스:궁합%,...
예: #g=%EC%A7%80%EC%88%98:0:91,%EB%AF%BC%EC%A4%80:4:87
```
- 닉네임: `encodeURIComponent()` 처리 (한글 포함)
- 대학인덱스: `universities_top100.json` 배열 위치 (0-based)
- 10명 기준 URL 길이 ~260자 (정상 범위)

## 핵심 로직

### 사주 오행 프로필 계산
- **년주**: 표준 60갑자 공식 — 천간 `(year-4)%10`, 지지 `year%12`
- **계절**: 월 → 오행 매핑 (봄=木, 여름=火, 환절기=土, 가을=金, 겨울=水)
- **일진**: `(day-1)%5` → 5행 (정통 일주 아님, 보조 신호)
- **가중치**: 년간 35% + 년지 25% + 계절 25% + 일진 15%

### 대학 오행 프로필
TRAIT_ELEMENT_MAP (traits → 오행):
```
목(木): 자유로운사고, 표현력
화(火): 도전정신, 사회적감각
토(土): 전통과격식
금(金): 논리력, 집중력
수(水): 전략적사고
```
- Tier1 (28개): 손큐레이션 3축 traits → 위 매핑으로 오행 변환
- 신규 75개: 대학 특성에 맞게 직접 traits 배정 (build_top100.py 참고)
- 언급 안 된 오행은 기본값 48 적용

### 매칭
- 사용자 오행 벡터(5차원) vs 각 대학 오행 벡터(5차원) → **코사인 유사도**
- 103개교 전부 계산 후 최고 유사도 학교 선택
- 궁합% = 유사도(0~1) → 78~99% 리스케일
- 타이브레이크: 학교명 해시 미세값

### SAT 필터링
- `satRange: [lo, hi]` 있는 미국 10개교만 대상
- 안정권(`score ≥ hi`) / 적정권(`lo ≤ score < hi`) / 도전권(`lo-80 ≤ score < lo`) → 후보 풀
- 폴백: 점수가 너무 낮으면 103개교 전체로 복귀

## 개선 방향 (다음 작업 후보)

### 우선순위 높음

**1. 인스타 스토리 이미지 export (PNG)**
- canvas 기반 1080×1920px 결과 이미지 생성
- 구성: 대학 크레스트(크게) + 궁합% + 오행 칩 + "superfastsat.com에서 나도 해보기"
- `html2canvas` CDN 추가 (1줄) 후 `exportStoryImage()` 함수 작성
- "📸 스토리 저장" 버튼을 기존 "결과 복사하기" 옆에 추가
- **바이럴 임팩트 가장 높음** — 이미지 1장이 인스타/카카오스토리에서 유기적 확산

**2. 그룹 보드 UX 개선**
- 그룹 보드에서 특정 대학 카드 클릭 시 → 그 대학 상세(모토/설명/오행 프로필) 모달
- 참여자 없는 빈 카드를 기본 숨김 후 "전체 보기" 토글 (현재 103개 모두 표시 → 산만)
- 그룹 내 "오행 분포 차트" 추가 (5명이면 5개 우세 오행 — 목2/화1/금2 식의 분포)

**3. 오행 유형 타이틀 (정체성 라벨)**
- "당신은 **금(金)의 인재**입니다" 헤드라인을 결과 카드 최상단에 추가
- 5개 유형: 木=성장형 / 火=추진형 / 土=안정형 / 金=정밀형 / 水=전략형
- 공유 텍스트에도 포함 → "나는 금의 인재, MIT 체질이래"라는 언어 생성

**4. 로딩 내러티브 3단계**
- 현재 단순 스피너(900ms) → 3단계 텍스트 전환
- "甲午年生 확인 중…" → "목(木) 기운 감지…" → "103개교 오행 대조 중…" → "궁합 발견!"
- 점집 경험 완성도 높임

### 우선순위 중간

**5. 배포 환경 결정**
- 현재: 로컬 Python 서버 필요 (fetch 때문에 file:// 불가)
- 옵션 A: Vercel/Netlify 정적 호스팅 → `data/` 폴더 그대로 배포
- 옵션 B: 기존 `landing_2512` Next.js에 `public/university_chem/` 하위에 통합
- **JSON 배포 경로 결정이 핵심** — HTML의 fetch 경로가 여기에 맞춰 바뀜

**6. 모바일 실기기 검증**
- 현재 반응형 CSS만 작성, 실제 iOS/Android 기기 테스트 미실시
- 특히 그룹 보드 그리드 레이아웃 모바일 확인 필요
- **친구 비교 모드 선행 조건** — 모바일 UX가 안정돼야 2인 비교 기능이 연결됨

**7. 친구 비교 모드 (2인 오행 궁합)**
- 두 생년월일 입력 → 두 오행 프로필 코사인 유사도 → "두 사람 오행 궁합 XX%"
- 각자 매칭 대학도 표시 ("나: MIT 체질 + 친구: 예일 체질 → 궁합 91%")
- 바이럴 루프 가장 강력 (2인 비교 = 구조적으로 R₀ ≥ 2)

### 우선순위 낮음

**8. Tier 2 설명 템플릿 뱅크 완성**
- `data/description_templates.json` 현재 미완성
- 15~20개 템플릿 (region × focus × 최강지표 슬롯 조합)
- 신규 75개교 현재 `tag` 한 줄만 있음 → `desc` 문장 추가 시 활용

## 제약/주의사항
- 실제 입시 결과나 대학 평가 기준과 무관한 엔터테인먼트 콘텐츠임을 UI에 명시 (하단 disclaimer 유지)
- 대학 모토: 공개된 라틴어/영어 단문 인용, 저작권 이슈 없음
- 픽셀 아트 배지: 실제 대학 로고 아님, 순수 알고리즘 생성 — "공식 로고"처럼 보이지 않도록 주의
- SAT 데이터: 2025-26 기준, 매 사이클 바뀜 → 실서비스 전 재검증 필요
- localStorage 미사용 (개인정보 저장 불필요)
- 카카오 로그인 불필요 — 닉네임 직접 입력 방식이 마찰 없어 바이럴에 유리
