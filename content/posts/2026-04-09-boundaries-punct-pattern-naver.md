## Boundaries 169문제, 정답에 가장 많이 등장한 구두점은?

Boundaries 문제를 처음 보면 쉼표를 써야 하나,
세미콜론을 써야 하나,
콜론을 써야 하나 이 세 가지에서 막히는 경우가 많습니다.

실제 데이터를 한 번 살펴보았습니다.
questionbank Boundaries 169개 모든 문제에서
뭐가 정답이었는지 말입니다.

| 정답 구두점 | 문제 수 | 비율 |
|---|---|---|
| 쉼표(,) | 48개 | 28.4% |
| 구두점 없음 | 43개 | 25.4% |
| 마침표(.) | 29개 | 17.2% |
| 세미콜론(;) | 23개 | 13.6% |
| 콜론(:) | 16개 | 9.5% |
| 대시(—) | 10개 | 5.9% |

정답의 1위는 쉼표입니다.
2위는 아무것도 넣지 않는 게 정답인 경우입니다.

이 두 가지가 전체의 53.8%를 차지합니다.
세미콜론(13.6%)과 콜론(9.5%)을 합쳐도 23%입니다.

보통 "세미콜론이랑 콜론이 제일 헷갈려요"라고 하는데
이건 고민할 때 주로 세미콜론·콜론에서 막히다 보니 그런데
실제로는 쉼표와 구두점 없음의 싸움이 더 자주 일어납니다.

## 정답 유형별로 보기는 어떻게 구성되나?

정답이 무엇이냐에 따라
보기에 어떤 구두점이 함께 등장하는지 패턴이 있습니다.

이번엔 "정답이 A일 때 보기에 B가 몇 %로 등장하는가"를
같은 169문제에서 집계했습니다.

| 정답 | 보기에 함께 등장하는 구두점 (비율 순) |
|---|---|
| 세미콜론(;) | 쉼표 91.3% / 구두점 없음 52.2% / 콜론 21.7% |
| 콜론(:) | 쉼표 75% / 구두점 없음 62.5% / 세미콜론 50% |
| 쉼표(,) | 구두점 없음 79.2% / 세미콜론 45.8% / 콜론 29.2% |
| 구두점 없음 | 쉼표 83.7% / 콜론 46.5% / 세미콜론 32.6% |
| 마침표(.) | 구두점 없음 89.7% / 쉼표 79.3% / 세미콜론 6.9% |
| 대시(—) | 쉼표 100% / 구두점 없음 70% / 콜론 60% |

세미콜론이 정답인 문제를 보면
보기에 쉼표가 91.3%로 등장합니다.

거의 무조건 쉼표와 대결합니다.

세미콜론 '규칙'을 외우는게 끝이 아니라
쉼표와 세미콜론 중 어느 게 맞는지 판단하는 문제입니다.

콜론이 정답인 문제는 조금 다릅니다.
보기에 세미콜론이 50%로 등장합니다.
콜론 문제의 절반은 콜론과 세미콜론을 동시에 보기에 놓습니다.

이 두 가지를 세트로 공부해야 하는 이유가 여기 있습니다.

반면 마침표가 정답인 문제에서는
세미콜론이 보기에 나오는 비율이 6.9%입니다.

마침표 문제에서 세미콜론을 고민하는 건
거의 없는 경우를 고민하는 셈입니다.

## 보기를 보면 어디에 집중해야 하는지 보인다

이 데이터가 실전에서 유용하려면
문제를 열었을 때 보기를 먼저 확인하는 습관이 필요합니다.

보기에 세미콜론이 있다면
이 문제는 독립절 연결 맥락일 가능성이 높습니다.
밑줄 앞뒤가 독립절인지 확인하는 방향으로 접근하면 됩니다.

보기에 세미콜론이 없다면
세미콜론 방향으로 고민할 필요가 없습니다.
그 시간을 아낄 수 있습니다.

보기에 콜론과 세미콜론이 동시에 있다면
두 구두점의 사용 조건 차이를 묻는 문제입니다.

콜론은 앞이 완전한 문장일 때, 뒤에 설명·열거·인용이 오는 구조입니다.
세미콜론은 앞뒤가 모두 독립절일 때 연결합니다.
이 차이 하나로 구분합니다.

콜론과 세미콜론은 이 포스팅도 한 번 참고해보세요.
https://blog.naver.com/superfastsat/224114028776?trackingCode=blog_bloghome_searchlist


보기에 구두점이 없는 선택지가 있다면
이 문제는 구두점을 넣어야 하는지, 말아야 하는지를 먼저 판단하는 문제입니다.


일단 이렇게 기억하세요.

세미콜론이 보기에 있으면 → 독립절 연결 맥락 확인
콜론이 보기에 있으면 → 앞이 완전한 문장인지 확인
콜론+세미콜론이 둘 다 있으면 → 두 구두점 조건 차이 판단
구두점 없음이 보기에 있으면 → 넣을 필요가 있는지 먼저 확인
