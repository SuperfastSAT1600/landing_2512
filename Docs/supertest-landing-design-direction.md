# SuperTest 랜딩페이지 — 디자인 디렉션

이 문서는 SuperTest 랜딩페이지 제작 시 Claude Code에 함께 전달하는 디자인 의도서입니다.
색상·폰트·카드 패턴 등 기본 스타일 규칙은 `landing-page-design-guide.md`를 따르고, 이 문서는 **페이지 구조, 감정 설계, 섹션별 연출 규칙**을 정의합니다.

---

## 0. 페이지 전체 설계 원칙

### 감정 흐름 (스크롤 순서 = 설득 순서)

```
Hero(한 줄로 꽂기)
  → Pain(불안 자극 — 공감)
    → Solution(해결 임팩트 — 신뢰)
      → Pricing(결정 유도 — 행동)
        → CTA(마무리 푸시)
```

- 섹션마다 감정 온도가 달라야 한다. 같은 톤으로 나열하면 평이해진다.
- Pain 섹션은 불편함을 만들고, Solution 섹션에서 해소한다. 이 긴장→해소가 설득의 핵심.

### 공통 레이아웃 규칙

- 섹션 제목(section-label + section-title + section-desc)은 **모두 가운데 정렬**.
- section-desc의 max-width는 600px, 좌우 auto margin.
- 모든 feature/solution 카드는 **비주얼(위) + 텍스트(아래)** 세로 스택 구조. 좌우 배치 금지.
- 각 카드는 full-width(grid-column: 1/-1)로 화면을 넉넉하게 사용한다.

## 1. Hero 섹션

### 목적
차별점을 한 문장으로 전달하고, 다음 시험일로 긴급성을 부여한다.

### 구성 요소
1. **라이브 배지**: 다음 시험 날짜를 표시. 초록색 깜빡이는 dot + 날짜 텍스트. `border-radius: 9999px`, 파란 반투명 배경.
2. **메인 카피**: "모의고사를 풀지 말고 / 시험을 치르세요" — 핵심 동사에 gradient text 강조(accent-glow → 보라). `font-size: clamp(2.2rem, 7vw, 4.5rem)`, weight 800.
3. **서브 카피**: 핵심 기능 3가지를 한 문장으로 요약. color: text-secondary.
4. **CTA 버튼 2개**: Primary(시험 신청하기) + Ghost(어떻게 다른가요?). 모바일에서 세로 스택.
5. **숫자 3개**: "2주 / 4개국 / 1,174+" 같은 핵심 스탯. accent-glow 색상, 가운데 정렬.

### 연출
- 배경에 radial-gradient glow (accent-primary 계열, 느린 pulse 애니메이션).
- 요소가 위에서 아래로 순차 fadeUp (badge → title → sub → CTA → stats, 각 0.2s 간격).

## 2. Pain 섹션 — "왜 점수가 안 오를까요?"

### 목적
학생/학부모가 "맞아, 우리 아이가 딱 이래"라고 공감하게 만든다. 불편함을 먼저 충분히 느끼게 해야 다음 Solution 섹션에서 해결책이 강력하게 와닿는다.

### 구조
- **인트로 영역** (60vh): 섹션 레이블("솔직한 이야기", 빨간색) + 제목 + 설명. 가운데 정렬.
- **풀스크린 슬라이드 3장**: 각 슬라이드가 100vh를 차지. 스크롤할 때마다 화면이 바뀌는 느낌.

### 슬라이드 공통 규칙
- 가운데 정렬. 이모지 아이콘(큰 사이즈, 3rem) + 제목(h3) + 설명(p).
- 제목의 **동사 부분**이 핵심. 나머지 텍스트는 white, 동사만 `#f87171` (빨간색) + weight 900.
- 각 동사에 **그 의미를 체감시키는 고유 애니메이션**을 적용한다.
- 배경에 동사의 의미를 보강하는 ambient 이펙트를 깐다.
- 스크롤 진입 시 IntersectionObserver로 `.visible` 클래스를 추가해 애니메이션을 트리거한다.

### 슬라이드별 동사 연출

#### 슬라이드 1: "무너진다"
- **동사 애니메이션**: 위에서 떨어지듯 등장(translateY + blur에서 선명하게) → 흔들리며 기울어지는 붕괴 모션(rotate, skew 조합). 글자가 물리적으로 무너지는 느낌.
- **배경 이펙트**: 작은 사각 블록 파편 8~10개가 제각각 다른 타이밍·방향으로 떨어진다. `position: absolute`, CSS custom property(--tx, --rot, --dur, --del)로 각 파편의 궤적을 개별 제어.
- **분위기**: 하단에 빨간색 그라디언트 안개가 서서히 나타남.

#### 슬라이드 2: "반복한다"
- **동사 애니메이션**: 글자가 fade-out → fade-in을 무한 반복하는 pulse. 끝나지 않는 루프 느낌.
- **배경 이펙트 (2가지)**:
  - 점선 원 2개가 서로 반대 방향으로 무한 회전. 빠져나올 수 없는 순환 시각화.
  - "반복한다" 고스트 텍스트 6개가 제목 주변 사방에 흐릿하게(opacity 0.06) 나타났다 사라짐을 반복. 각각 다른 위치(--x, --y)와 타이밍(--del).

#### 슬라이드 3: "정체된다"
- **동사 애니메이션**: 넓은 letter-spacing + blur에서 시작 → 자간이 좁아지며 선명하게 "멈춘다". 최종 상태가 움직이지 않는 것 자체가 연출.
- **배경 이펙트**: 하단에 SVG 라인 그래프. 왼쪽에서 오른쪽으로 stroke-dashoffset 애니메이션으로 그려지는데, 처음엔 올라가다가 중반부터 수평선이 되어 더 이상 올라가지 않음. 끝에 "점수 변화 없음" 텍스트.

### 모바일 처리
- 슬라이드 높이 80vh로 축소.
- 파티클, 회전 링, 고스트 텍스트 등 GPU 부하 요소는 모바일에서 `display: none`.
- SVG 그래프의 width를 85%로 조정.

## 3. Solution 섹션 — "다른 모의고사와 무엇이 다른가"

### 목적
Pain에서 만든 불편함을 해소한다. "이 문제, SuperTest가 이렇게 해결한다"를 구체적으로 보여준다.

### 구조
- 섹션 제목 (가운데 정렬) + **카드 4장** (세로 스택, 모두 full-width).
- 각 카드는 **상단: 움직이는 비주얼 / 하단: 텍스트 설명** 구조.
- 카드 내부에 `solution-number`(레이블), `h3`(제목), `p`(설명)을 포함.

### 카드별 상세

#### 카드 1: 화상 카메라 동시 응시 (핵심 차별점)
- **비주얼**: 라이브 시뮬레이션 UI 재현.
  - 중앙에 큰 타이머(2.8rem, weight 800, text-shadow glow). 실시간으로 1초씩 카운트다운되는 JS 인터벌.
  - 타이머 옆에 초록색 "LIVE" 인디케이터 (dot + glow shadow + blink 애니메이션).
  - 아래에 국가별 참가자 pill들 (국기 이모지 + 도시명). 각 pill이 시차를 두고 opacity pulse — 동시에 사람들이 접속해 있다는 느낌.
- **텍스트 영역**: 제목 + 설명 + 시간대 pill 4개 (KST/EST/PST/ICT, 각각 시간 표시).
- **배경**: 위에서 아래로 파란색 그라디언트 (accent-primary 12% → 4%).

#### 카드 2: Micro-skill 약점 분석 (정밀 분석)
- **비주얼**: 스킬 트리 UI.
  - 5개 스킬 노드가 세로로 나열. 각 노드: 색상 dot + 스킬명 + 점수.
  - 약한 스킬(빨강 테두리/배경), 보통(노랑), 강한(초록)으로 색상 구분.
  - 각 노드 내부에 `::after`로 fill bar가 있고, 스크롤 진입 시 IntersectionObserver로 순차적(200ms 간격) fill 애니메이션 트리거. `--fill` CSS 변수로 각 노드의 채움 비율 지정.
- **텍스트 영역**: College Board와의 정밀도 차이 강조. "1,174개 스킬" 수치 포함.
- **배경**: teal → 파란 그라디언트.

#### 카드 3: 2주마다 열리는 정기 일정 (정기 훈련)
- **비주얼**: 수평 타임라인.
  - 6개 회차 노드가 점과 선으로 연결. 1회차는 glow가 있는 활성 상태.
  - 스크롤 진입 시 노드가 순차적(300ms 간격)으로 밝아지고, 각 연결선이 왼쪽→오른쪽으로 채워지는 애니메이션.
  - 하단에 "2주 간격" 인터벌 레이블.
- **텍스트 영역**: 정기성이 점수에 미치는 영향 설명.
- **배경**: accent-glow 10% 그라디언트.
- **모바일**: 타임라인 overflow-x: auto, 가로 스크롤.

#### 카드 4: 시험 후 단어 정리 (사후 학습)
- **비주얼**: 단어 카드 스택 UI.
  - 5개 단어 아이템이 세로 나열. 모르는 단어(빨간 배경/테두리, ❌ 표시) vs 아는 단어(회색, ✓ 표시).
  - 스크롤 진입 시 각 카드가 왼쪽에서 순차적(150ms 간격) 슬라이드인.
  - 마지막에 요약 바("3개 몰랐던 단어 → 자동 학습 리스트 생성")가 페이드인.
- **텍스트 영역**: 자동 추출 + 별도 정리 불필요 강조. "Live, Flex 한정" 명시.
- **배경**: 노란색(eab308) 8% 그라디언트.

## 4. Pricing 섹션 — "나에게 맞는 플랜은?"

### 목적
기능 비교가 아니라 **"나에게 맞는 것"을 고르게** 만든다. 선택 장벽 제거.

### 구조
- 섹션 제목 (가운데) + 할인 배지 + **카드 3장** (3컬럼 그리드, 모바일 1컬럼).

### 카드 공통 구조 (위에서 아래 순서)
1. **인기 배지** (Live 카드만): `position: absolute; top: -14px`, accent-primary 배경.
2. **플랜 이름** + 한 줄 태그라인.
3. **추천 대상 안내**: "💡 처음 시작하는 학생에게 추천" / "⏰ 시간이 안 맞는 학생" / "📝 해설만 필요한 학생". 파란 반투명 배경 박스. — 이것이 핵심. 사용자가 자기 상황에 매칭할 수 있어야 한다.
4. **가격**: 원가(취소선) + 할인가(큰 폰트, 2.5rem weight 800) + 할인율 레이블.
5. **기능 리스트**: ✓/✕ 체크리스트. 비활성 항목은 color #555.
6. **응시 기한**: 구분선 위에 작은 텍스트.
7. **CTA 버튼**: Live = Primary(solid blue), Flex/Review = Outline.

### 추천 카드(Live) 강조
- border-color를 accent-glow 40%로 올리고, box-shadow로 파란 glow 추가.
- 다른 카드와 시각적 무게 차이가 명확해야 한다.

### 연출
- 스크롤 진입 시 3장이 순차적(0 → 100ms → 200ms) fadeUp.

## 5. CTA 섹션 — 마무리

### 목적
마지막 푸시. 다음 시험까지 남은 긴급성을 상기시킨다.

### 구성
- 제목: "다음 시험, 이번에는 제대로 치르세요"
- 서브: 남은 일수 or 시험 시작 시점 안내.
- Primary CTA 버튼 1개.
- 하단에 다음 시험일 강조 (날짜 부분만 accent-glow + bold).
- 배경에 radial-gradient glow (Hero와 동일한 패턴으로 시작과 끝의 일관성).

## 6. 애니메이션 공통 규칙

### IntersectionObserver 패턴
- 모든 카드/슬라이드는 초기 상태 `opacity: 0; transform: translateY(30px)`.
- 뷰포트 진입 시(threshold: 0.15) `.visible` 클래스 추가.
- `data-delay` 속성으로 동일 섹션 내 순차 등장 타이밍 제어.
- observe 후 unobserve (한 번만 실행).

### 비주얼 내부 애니메이션
- 각 비주얼(스킬 트리, 타임라인, 단어 카드 등)은 별도 IntersectionObserver(threshold: 0.3)로 세부 요소를 순차 트리거.
- 순차 간격: 스킬 노드 200ms, 타임라인 노드 300ms, 단어 카드 150ms.

### 모바일 성능
- `backdrop-filter` → 불투명 배경으로 대체.
- 무한 반복 애니메이션, 파티클, 회전 링 → 모바일에서 display: none.
- `@media (prefers-reduced-motion: reduce)` → 모든 animation/transition 제거, opacity/transform 초기화.

| 구간 | 주요 변경 |
|------|----------|
| ≥1024px | Solution/Pricing 원래 레이아웃 |
| 768px~1023px | Solution 카드 1컬럼, 타임라인 가로 스크롤 |
| ≤768px | Pain 슬라이드 80vh, 배경 이펙트 숨김, Pricing 1컬럼(max-width 420px), CTA 버튼 세로 스택 |
