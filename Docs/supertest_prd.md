# SuperTest 랜딩 페이지 기획 문서 (PRD 초안)

## 1. 프로젝트 개요
- **목적**: 광고를 통해 유입된 고객에게 'SuperTest'의 필요성을 설득하고 결제 페이지로 유도하는 랜딩 페이지 제작
- **주요 기능**: SuperTest 서비스 특장점 소개, 3가지 응시 상품 비교 및 외부 결제 링크(CTA) 연결
- **핵심 목표**: 유입된 사용자의 구매 전환율 극대화 (특히 5/30 첫 시험의 첫 할인 이벤트 강조)

## 2. 타겟 고객 (Target Audience)
- SAT 시험을 준비하며 실전 감각을 극대화하고 싶은 학생
- College Board보다 정교한 'Micro-skill' 단위의 약점 분석이 필요한 학생
- 모의고사 이후 모르는 단어 정리와 전문가 해설로 완벽한 오답 노트를 만들고 싶은 학생

## 3. 핵심 소구점 (Key Value Proposition)
- **조금 더 어렵게, 실제 시험처럼**: 실제 SAT보다 약간 더 높은 난이도로 설계되어 어떤 변수에도 흔들리지 않는 실력을 완성합니다. 실제 시험과 동일한 시간, 화상 카메라 접속을 통한 완벽한 긴장감을 부여합니다.
- **초정밀 약점 분석**: College Board보다 훨씬 더 자세한 'Micro-skill' 레벨의 약점 기록과 실시간/기간 제한 응시자 데이터 기반의 정확한 성적 비교를 제공합니다.
- **모르는 단어 완벽 마스터**: 시험 종료 후, 이번 시험에서 몰랐던 단어만 따로 체크하고 학습할 수 있는 전용 단계를 제공합니다. (Live, Flex 상품 한정)
- **전문가 밀착 리뷰**: 사전에 고객에게 안내된 1시간의 시험 리뷰 강의 시간에 맞추어 접속하면, 핵심만 짚어주는 코치의 해설을 들을 수 있습니다.

## 4. 페이지 구성안 (Information Architecture)

### Section 1: Hero Banner (메인 배너)
- **헤드라인**: "조금 더 어렵게, 실제 시험처럼. 가장 완벽한 SAT 실전 모의고사 SuperTest"
- **서브카피**: 혼자 푸는 쉬운 모의고사는 끝났다. 화상 카메라 모드의 실전 환경부터 College Board를 뛰어넘는 초정밀 분석까지.
- **프로모션 강조 배지**: **"5/30 시작, 첫 할인 이벤트 30%"**
- **CTA 버튼**: [첫 할인 30% 적용받고 신청하기] (클릭 시 가격 비교 섹션으로 스크롤 이동)

### Section 2: Problem & Solution (왜 SuperTest인가?)
- **공감대 형성**: 혼자 푸는 모의고사로는 실제 시험장의 긴장감을 경험할 수 없고 점수 정체기가 온다는 페인포인트 자극
- **해결책 제시**: 실제 시험보다 '조금 더 어려운' 난이도와 화상 카메라를 켜고 타 학생들과 함께 접속하는 시스템으로 집중력을 극대화하는 SuperTest만의 차별점 시각화

### Section 3: Features (상세 장점 소개)
1. **2026년 정기 실전 일정표**: 5월 30일부터 2주 간격으로 꾸준히 이어지는 2026년 전체 실전 훈련 일정을 확인할 수 있도록 제공.
2. **글로벌 동시 접속**: 타 학생들을 화면으로 확인하며 SAT 시작 시간에 맞추어 동시 응시. (**※ 국가별로 실시간 시험 시작 시간이 다르다는 점 별도 안내**)
3. **Micro-skill 약점 분석**: College Board보다 상세한 스킬 단위 분석과 실시간/기간제한 응시생 데이터가 통합된 정교한 내 위치 파악.
4. **어휘(단어) 집중 학습**: 시험이 끝난 직후 모르는 단어를 체크하여 학습할 수 있는 필수 마무리 단계 제공.
5. **리뷰 강의**: 안내된 리뷰 강의 시간에 접속하여 시청하는 코치의 1시간 집중 해설.

### Section 4: Pricing & Products (상품 비교 및 결제 CTA)
- 3가지 옵션에 대해 직관적인 **가칭 네이밍(Live / Flex / Review)**을 부여하여 비교 표 제공.
- 첫 할인 이벤트(30%)를 시각적으로 강력하게 강조.

| 구분 | SuperTest Live (실시간 응시) | SuperTest Flex (기간 제한 응시) | SuperTest Review (기간 무제한 응시) |
| :--- | :--- | :--- | :--- |
| **특징** | 완벽한 실전 긴장감 | 유연한 일정 + 성적 분석 | 오답 정리 및 해설 집중 |
| **기한/일정** | **시험 날 기준 오전 11시 30분** | **시험 종료 시간 + 48시간** 내 | **시험 종료 시간 + 30일** 내 |
| **화상 카메라** | O (타 학생 확인 가능) | X | X |
| **단어 학습 기능** | O | O | X |
| **성적/약점 분석** | O (Micro-skill 분석 및 성적 비교) | O (Micro-skill 분석 및 성적 비교) | X |
| **해설 강의** | O (안내된 리뷰 시간에 1시간 접속) | X | O (30일 내 자유롭게 시청) |
| **정가** | 70,000원 | 40,000원 | 20,000원 |
| **할인가(30%)**| **49,000원** | **28,000원** | **14,000원** |
| **CTA 버튼** | [Live 결제하기] | [Flex 결제하기] | [Review 결제하기] |

*모든 금액은 부가세가 포함된 가격입니다. 결제 버튼 클릭 시 준비된 외부 결제 페이지로 이동합니다.*

### Section 5: FAQ (자주 묻는 질문)
- **환불 규정**: 
  - 정해진 기한 내에 사전에 취소할 경우: **환불 가능**
  - 상품별 기한 내에 응시하지 않았을 경우 (노쇼 등): **환불 불가**
- **응시 환경 세팅**: 화상 카메라 세팅 방법, 국가별 실시간 시작 시간 확인 방법 등.

## 5. UI/UX 및 개발 시 고려사항
1. **타임존 기반 시간 안내**:
   - 국가별로 시험 시작 시간이 다르므로, 접속 유저의 국가/타임존을 기반으로 직관적으로 시간을 안내할 수 있는 UI 구현 (또는 주요 국가별 시간표 제공).
2. **2026년 전체 일정표**:
   - 5/30부터 2주 간격으로 진행되는 시험 일정을 시각적인 타임라인이나 캘린더 컴포넌트로 구현하여 꾸준히 학습할 수 있다는 점을 어필.
3. **할인 정책 컴포넌트화**:
   - 향후 마케팅 전략에 따라 할인율 변경이 예상되므로, 프론트엔드 코드 내에 할인율 변수를 별도로 두어 쉽게 수정할 수 있도록 개발.
4. **상품 네이밍**: 
   - 기획안에 임시로 제안된 **Live / Flex / Review** 등의 상품명은 최종 확정된 명칭으로 교체하여 적용 필요.
